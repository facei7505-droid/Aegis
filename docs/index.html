Directions for use

1

Detect 0.1 ms

Every value is decoded and scored against 10 attack classes, plus what this app's normal traffic looks like.

2

Block

403 in block mode, auto-ban for repeat offenders. In monitor mode it watches and heals.

3

Locate

Maps the request to its handler, through blueprint prefixes and into helpers in other modules.

4

Patch

Deterministic fixes first; Claude for the rest, inside guardrails and a hard spending cap.

5

Verify

Compiles, the hole is gone, nothing new appeared, your tests pass on a copy.

6

Canary

A copy runs the patch; recent real requests must answer as before, or the patch is refused.

Take it

pip install -e ".[demo]"
aegis demo           # the whole loop in one second
aegis range          # DSVW + vulpy + VulnShop behind one gateway
aegis gateway -c gateway.toml   # your own apps, any language

Python 3.10+, no runtime dependencies in the core. Code healing needs Python source; the shield protects any HTTP app.

Known side effects

  • Signatures miss some payloads (28 of 30 on a frozen held-out set); the code fix is the real cure.
  • A learned profile on a fast-changing site will raise more false alarms than on CSIC's closed shop.
  • Taint follows plain function calls, not methods or objects. Python only.
  • Argument injection (values starting with -) is not handled by the command fixer.
  • Two outside reviewers and real attack tools found 26 real problems; each is fixed with a test (REVIEW.md).
