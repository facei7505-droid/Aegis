How Aegis works

Aegis traces attacker-controlled data (HTTP parameters, cookies, headers, path parameters) through the code to dangerous operations. Every automatic patch must pass four gates before it is accepted: the file compiles, the vulnerability is gone, no new issue appeared, and the project's own tests still pass. Patches proposed by AI go through exactly the same gates.
