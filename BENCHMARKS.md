# Aegis v1.0.0 — benchmarks

Generated by `python benchmarks/run.py` on Python 3.13.18. Every number below is reproducible.

## 1. Shield: attack detection

- Attack corpus: **89 payloads** in 7 classes, including URL/double-URL/HTML-entity encoding, mixed case and SQL comment padding (`benchmarks/data/attacks.tsv`).
- Benign corpus: **146 real-world inputs** that trip naive filters: `O'Brien`, `rock & roll`, `C#`, `<3`, Kazakh/Russian addresses, code snippets from support tickets (`benchmarks/data/benign.txt`).

| Metric | Value |
| --- | --- |
| Detection rate | **100.0%** (89/89) |
| False-positive rate | **0.0%** (0/146) |
| Median inspection time per value | 27 µs |
| p99 inspection time per value | 71 µs |

> Honest caveat: both corpora are small and were used while the detectors were written (they include
> every bypass and false positive found by an independent review), so these numbers are an upper bound.

**Held-out check.** After tuning, a second set was written and frozen: it is never used to change the
detectors (`benchmarks/data/heldout_*`).

| Held-out metric | Value |
| --- | --- |
| Attacks detected | **28/30** |
| Benign inputs flagged | **0/30** |

Held-out misses: `1' ORDER BY 3--`, `'||(SELECT version())||'`. A signature WAF is one layer: these are why Aegis also fixes the code itself.
